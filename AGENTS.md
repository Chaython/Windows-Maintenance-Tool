# Project guidance

- Read [README](README.md) and [contribution guidance](CONTRIBUTING.md) first.
- Keep changes focused; preserve unrelated work and existing behavior.
- Present significant design or dependency changes for approval before editing.
- Use `.temp/<task-id>/` for disposable non-secret fixtures. Remove only your own
  files; never broadly clean the workspace.
- Never read, print, commit, or transmit secrets or private keys without explicit
  permission.
- Do not request passphrases in chat or bypass interactive encryption prompts.
- Do not install/start MCP servers or approve their tools automatically.
- Report failures and unverified behavior explicitly.
- Keep all documentation current.
